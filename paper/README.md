# Scientific Reports Overleaf manuscript

Upload the contents of this folder to a new Overleaf project and set `main.tex` as
the main document. The project uses the official Springer Nature `sn-jnl` class in
the single-column Nature Portfolio configuration and the `sn-nature` bibliography
style. The required class and bibliography-style files are included.

Before submission, replace the placeholders in `main.tex`:

1. the GitHub repository URL in the Reproducibility and Code availability sections;
2. funding information, if applicable;
3. ORCID identifiers, if desired;
4. the competing-interests wording if any author has a relevant interest.

The manuscript is prepared for submission to Scientific Reports and its Guest Edited
Collections. It follows the journal's Article format, uses no acknowledgement section,
and includes Author contributions, Data availability, Code availability, Ethics,
Competing interests, and generative-AI-use declarations.

The numerical results are imported as static figures and tables generated by the
reproducible Python simulation in the parent folder. The paper deliberately labels
the work as simulation-only and the BMI response model as an unvalidated parametric
hypothesis. All submission files and figures are placed in the project root to avoid
path problems in Springer Nature's submission system.

Compile with pdfLaTeX and BibTeX. Overleaf normally performs the required sequence
automatically when `references.bib` is present.
